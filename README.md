# 无界鼠标 · 中文增强版

一套键盘和鼠标，在两台 Windows 电脑之间自然切换；文件拖到哪个文件夹，就在那里接收。

本项目基于 **Microsoft Garage Mouse without Borders 独立版 2.2.1.0327** 制作，由社区独立维护。原项目由微软员工 **Truong Do** 开发，支持一套键鼠控制多台电脑。本项目提供中文界面与文件传输增强，是独立版的增强工具，不是微软官方发行版，也不是 PowerToys 的分支。

原项目：[微软官方下载](https://www.microsoft.com/en-us/download/details.aspx?id=35460)。另一个由微软维护的开源实现位于 [Microsoft PowerToys](https://github.com/microsoft/PowerToys/tree/main/src/modules/MouseWithoutBorders)，与这里使用的独立版属于不同发行版本。

## 新增功能

- **中文设置界面**：浅色布局，更清晰的设备排列、连接设置和选项。
- **指定文件夹接收**：支持拖入资源管理器内容区，或另一台桌面上的实际文件夹图标；目标文件夹显示简洁边框。
- **拖拽状态可见**：远端鼠标旁显示小文件图标，表示正在拖动文件。
- **双端传输窗口**：发送端和接收端都显示进度、大小与速度，小文件也有传输提示。
- **两端都能取消**：任意一端点击“取消传输”，两端停止本次传输。
- **不保留传输历史**：窗口关闭后清除本次显示信息，不提供历史记录列表。
- **拖回来源电脑**：恢复 Windows 原生拖拽，可继续在来源电脑选择投放位置。
- **界面与键盘修复**：改善缩放显示，取消设置窗口始终置顶，修复跨屏后键盘无法转发的问题。

原版已有的跨机鼠标、键盘、剪贴板共享仍然保留。

## 下载和安装

到 [Releases](https://github.com/yu-hx-tom/mouse-without-borders-zh/releases) 下载 **MWB-ZH-v9.0.0.11-Windows.zip**。当前作为测试版发布。

1. 在两台电脑上安装微软官方 **Mouse without Borders 2.2.1.0327 独立版**，并按原版向导完成连接。
2. 准备 [PowerShell 7](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows)。增强包会检测它是否已安装。
3. 解压增强包，在两台电脑上分别双击 **安装增强版.cmd**，按提示完成管理员授权。
4. 等待更新完成，按桌面上的左右位置排列设备并应用设置。已有配对会保留。

升级会短暂暂停跨机键鼠共享。请先完成正在进行的文件传输，再运行安装。

本包只包含本项目的扩展、源码和工具。微软原版程序由用户自行从微软获取，增强程序在用户电脑上生成；仓库和 Release 不包含微软原版或修改后的主程序、helper、服务程序。原版仍适用微软的许可条款。

## 使用方法

**跨机键鼠**：将鼠标移到屏幕边缘即可进入另一台电脑；点击需要操作的窗口，再正常使用键盘。

**传文件**：按住一个文件，拖到另一台电脑的文件夹内容区或实际文件夹图标上。看见目标边框后松开，文件会传到该目录，两端显示进度与速度。无法识别目标时，会请你选择接收目录。

**拖回本机**：保持按住鼠标左键，将文件拖回来源电脑，继续按 Windows 原来的方式投放。

**取消**：点击任意一端传输窗口里的“取消传输”。接收端不自动删除本次留下的未完成文件，请按需要自行处理。

**恢复升级前版本**：双击 **恢复升级前版本.cmd**。恢复的是增强安装前保存的版本；如果那时已经是旧增强版，恢复后也可能重新出现旧版的问题。

## 当前支持范围

| 系统 | 当前兼容情况 |
| --- | --- |
| Windows 10 x64 | 已实际使用，跨机键盘修复已确认；仍作为测试版发布。优先使用 2004–22H2 / 对应 LTSC 版本。 |
| Windows 10 x86（32 位） | x86 构建及回放检查通过，尚未完成真实 32 位设备验收。 |
| Windows 11 x64 | 面向该系统进行界面与拖放兼容处理；完整双机、资源管理器多标签页等仍待验收。 |
| Windows on ARM / ARM64 | 未验证，不承诺兼容。 |
| Windows 7 / 8 / 8.1 / Windows Server | 微软原版支持部分版本，但本增强包没有做兼容验收，不列入支持范围。 |
| macOS / Linux | 暂不支持。 |

两台 Windows 可以使用不同系统版本，但建议安装同一增强版本。请先确认微软独立版键鼠共享正常，再安装本包；需要 PowerShell 7 与可用的 .NET Framework。

- Windows 11 及未验证的 Windows 构建上，部分非文件拖动的自动结束路径会保守停用，异常时需按 Esc 解除等待。
- 当前跨机拖放按 **单个文件** 处理；多个文件或文件夹请先压缩成一个文件。
- 文件夹快捷方式、虚拟目录、网络目录，以及部分 OneDrive 目录可能无法直接识别，需要手动选择本机目录。
- 慢网络下，按住文件跨屏时可能短暂停在边缘，待准备完成后再次移动即可。
- 遇到原生拖拽一直未结束，可按 Esc 解除等待；回到来源电脑后若仍在拖动，再按 Esc 结束。
- 暂不支持 macOS / Linux，也不提供与旧增强版混用的保证。两端建议使用同一版本。

键盘修复已在本机真实跨机使用中确认；其他功能的离线检查已通过，测试版仍欢迎反馈具体使用问题。
